# Candidate pipeline
The candidate pipeline connects operator-selected repository, immutable context, model proposal, temporary Git index and independent diff review. The integration test exercises real Git and a mock model, without a laptop, API credentials or network. It returns a detached candidate only; no branch, push, PR, CI execution of generated source, or deployment. Do not supply an untrusted repository path or a remote model. Model integration, artifact retention, durable queue integration and isolated test execution remain open. The model interface must enforce privacy and free-only admission independently; the existing local-only proposal interface is not a cloud provider authorization.
