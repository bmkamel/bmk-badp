# BADP R1 — Operating charter
Vision: an independent cloud-native autonomous software development platform, capable of maintaining itself and eventually multiple authorized projects, operated from mobile without a continuously running personal computer.
Mission: turn approved objectives into inspected, scoped, tested, reviewable changes and verified deployments. Economy first: no paid services or quota bypass without explicit approval. Protect secrets, data and other projects.
Operating loop: read charter and project context; inspect current repository and base commit; select one authorized task; plan; generate a bounded patch; validate scope; execute isolated tests without credentials or network; publish evidence; create PR; merge only under trusted policy; verify deployment; record outcome. Stop on ambiguity, stale base, failed checks or cost/security risk.
Competitive reference set (initial hypotheses, not a current market audit): Devin (autonomous engineering), GitHub Copilot coding agent and OpenAI Codex (repository task execution), OpenHands and OpenCode (agent tooling), Lovable and Replit Agent (application building). Differentiate through governed multi-project operations, zero-spend controls, portable providers, auditable evidence and Arabic/English mobile operations. Do not claim superiority without benchmarks. Continuous evidence-based research and controlled self-improvement are R1 scope under owner direction 2026-11-28. Research official sources, inspect actual gaps, rank improvements, execute scoped changes through trusted gates, verify deployment and automatically claim the next task. Chat commands must create durable engineering tasks; advisory drafts do not count as execution. Preserve existing authority, budget and security boundaries.
R1 first task: make the autonomous pilot repeat-safe and expose a truthful task lifecycle. Inspect scripts/source-live-pilot.mjs and scripts/publish-source-pilot.mjs; the original formatting pilot is already merged. Do not repeat it or invent progress. Acceptance: completed pilot recognized without model call; no duplicate branch/PR; tests cover completed and pending states; real run evidence recorded. General source modification remains gated until a trusted task-specific verifier exists.
