# Cloud-only execution decision
GitHub-hosted Linux runners are the initial execution target; no local computer, local Ollama, or self-hosted runner is required. Groq and OpenRouter remain optional free-only providers subject to verified account limits. Cloudflare and Supabase are deferred until an end-to-end cloud cycle is proven.
The synthetic Docker smoke script checks a non-root, read-only, network-disabled container without mounting repository files or passing provider credentials. It is not yet wired to the source verifier and is not a security certification. Run only on an approved runner after verifying available free minutes and billing limits; pull and verify a pinned image digest before running untrusted source. No new scheduled workflows, deployments, secrets, or paid resources are enabled by this change.
Acceptance gates: verified free budget, pinned runtime, isolated synthetic smoke, trusted snapshot application, independent test evidence, separate draft PR publisher, and explicit review before merge.
