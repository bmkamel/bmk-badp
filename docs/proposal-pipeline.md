# Repository proposal pipeline
The snapshot reader extracts explicitly selected regular UTF-8 files from an immutable Git commit, not the mutable working tree. The proposal runner connects a trusted project registry, snapshot reader and injected local model to the existing proposal validator. Only modifications to inspected files are admitted; no files are written and no model-generated commands run. The model contract needs a repository-specific prompt and real local integration; current tests use mock inference. The existing static Ollama prompt is not yet suitable. The operator must supply a trusted repository path, local-only model and approved file selection. Secret detection is limited. Next: local repository-specific model adapter, durable proposal artifact storage, independent Git tree construction and isolated CI. No publication or deployment.
