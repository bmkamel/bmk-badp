# Hybrid runtime
Approved architecture: Groq primary, OpenRouter fallback, optional Ollama local; GitHub execution first, Cloudflare scheduling and isolated Supabase persistence later. The hybrid composition uses transport-level durable admission exactly once per outbound attempt, bypassing the separate model gateway reservation. Only explicitly public prompts reach cloud providers; context is not forwarded. No live keys, paid fallback, deployment or automatic merge. Next gates: trusted project classification, persistent runner wiring, provider-specific quotas, end-to-end isolated self-development and cloud scheduler.
