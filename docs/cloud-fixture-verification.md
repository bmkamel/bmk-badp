# Cloud fixture verification
Run only after verifying the account's free execution allowance. On an approved GitHub-hosted Linux runner, pre-pull a reviewed immutable Node image digest and set BADP_SMOKE_IMAGE to node@sha256:<digest>. Run bash scripts/cloud-fixture-verify.sh. The script refuses mutable image tags, runs the isolation probe, then checks a fixed synthetic replacement in ephemeral tmpfs. No repository files, provider credentials, or model output enter the container. This is a manual acceptance probe, not an autonomous executor or proof of comprehensive isolation. Existing CI does not run this probe. No new workflows or schedules are activated.
