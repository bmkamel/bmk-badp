# Bounded Git proposal materialization
A trusted process reconstructs and verifies the proposal digest, uses a temporary Git index against the pinned base commit, writes only Git objects, constructs a detached candidate commit, and independently reviews its diff. The current branch, working tree and real index are untouched. Only existing regular files may be changed. The candidate is not published and may be garbage collected if no trusted ref retains it. Use only an operator-provisioned repository; this is not a sandbox for arbitrary repositories or generated executable code. CI and approval remain separate, and no credentials are supplied. The test uses a disposable local Git repository; no laptop or live model is needed.
