# Groq primary cloud candidate
Groq transport supports GPT-OSS 120B and 20B with fixed endpoint, bounded request/response and no automatic retries. The repository model adapter accepts this transport through its invoke interface. Before activation, verify the dedicated Groq organization's Free plan, privacy settings and current limits in https://console.groq.com/docs/rate-limits. The boolean freePlanVerified is trusted configuration, not proof of billing status. A durable quota admission implementation and secure runtime credential are required. No live calls or credentials are included. On HTTP 429 stop and defer work; never upgrade or switch to paid service automatically. Public-source disclosure must be approved independently.
