# Local scheduler
Run node scripts/local-runner.mjs watch to poll the dedicated queue continuously, or drain for one pass. Both acquire an exclusive SQLite write lock in a separate worker database, released when the process exits. This prevents concurrent workers using the same local directory, not workers on other machines or direct Ollama clients. SIGINT/SIGTERM stop new work after the current run completes. Abrupt termination requires lease expiry before recovery. No automatic Windows startup or service installation yet; no live model test or arbitrary repository execution. The queue remains limited to static applications.
