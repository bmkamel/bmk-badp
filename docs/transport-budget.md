# Strict transport budget
Use a separate dedicated SQLite database. Admission atomically checks fixed UTC minute and day request limits and a daily local budget of input bytes plus maximum completion tokens. This mixed-unit budget is not a provider tokenizer or proof of free billing. Missing request dimensions deny admission. A persisted clock high-water mark rejects backwards time after successful reservations. No refunds. All workers must share the same database and trusted policy. Live integration remains disabled pending provider-specific token/rate limits and verified free eligibility.
