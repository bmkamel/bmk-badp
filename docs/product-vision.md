# BADP product vision
Independent multi-project application builder with conversational editing, source tree, isolated preview and continuous autonomous improvement. Economy-first, monthly target USD 10 excluding existing ChatGPT subscription. No paid execution by default.
First vertical slice: prompt -> structured plan -> isolated branch -> patch -> build/test -> bounded repair -> preview -> review. Production deployment and policy changes require independent approval.
Acceptance: build a small application from a prompt, modify it through conversation, demonstrate preview, preserve source and audit trail, resume interrupted work, reject cross-project access, stop at budget or retry limits. No claim of Lovable parity until benchmarked.
