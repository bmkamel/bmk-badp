# Early self-development proposal path
The pure proposal builder accepts explicitly enabled project configuration and bounded complete text replacements. It binds exact content, project, repository, base SHA, requested engine and DEV branch into an immutable digest. This offers a non-executing route for collecting model suggestions while the OS sandbox is unresolved. It does not invoke Aider, OpenCode or Ollama, apply patches, verify the base tree or publish. Engine names are requested metadata, not evidence of execution. Secret patterns are partial defense only. Next: trusted repository snapshot reader, model-to-proposal adapter, independently verified tree construction, isolated CI and approved publication. Never execute a proposal merely because it passes path policy.
