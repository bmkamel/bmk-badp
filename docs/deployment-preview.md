# Preview deployment gate
Use a dedicated Worker and D1 database. Configure Cloudflare Access with explicit owner allowlist and verified application audience. Set ACCESS_ISSUER and ACCESS_AUDIENCE in deployment configuration, bind DB, apply migrations in order and provision identity mapping through an authorized administrator. No public data API without verified identity. Disable paid AI and all mutation routes. Verify billing, access policy, health and tenant isolation before exposing the preview. Static chat remains local-only until authenticated message storage is implemented.
