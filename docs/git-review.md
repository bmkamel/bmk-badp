# Independent Git review
Review two immutable commit IDs in an operator-provisioned trusted local repository. Git supplies path, status, tree mode and blob size; policy rejects deletes, executable modes, symlinks, submodules, protected paths, oversized changes, binary and invalid UTF-8 content. A minimal secret-pattern check is defense in depth only, not comprehensive secret detection. No checkout, push, generated code execution or agent invocation. The repository path must be trusted; Git configuration and executable provenance require operator isolation. Before publishing, bind the reviewed head SHA to independent CI and approval, validate repository identity, and add a stronger secret scanner. No production mutation.
