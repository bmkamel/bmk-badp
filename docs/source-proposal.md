# Source proposal boundary
The validator accepts at most eight existing, explicitly allowlisted flat src/test .mjs paths, binds each replacement to a trusted snapshot hash and base commit, rejects duplicate edits and common credential patterns, and caps replacement bytes. It returns inert proposals only. No filesystem writes, execution, credentials, or network. This is not a sandbox or proof of safe code; a trusted caller must load the snapshot from the pinned commit and verify it again before application. New files, workflow changes and deletions are deliberately unsupported. Next gate: isolated execution with independent verification and no secrets.
